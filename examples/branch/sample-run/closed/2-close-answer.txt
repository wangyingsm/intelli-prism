Image uploads failed from 14:02 to 14:20 UTC, about 18 minutes. A deploy at 14:01 shipped a configuration with the wrong S3 bucket name, which caused the failures. Rolling back that deploy restored uploads immediately, and every upload since has succeeded. Roughly 300 users saw an error toast during the window; no users remain affected. Follow-up: add a validation check on bucket name configuration to the deploy pipeline so a mistyped or stale value fails the build rather than reaching production.
